# GenAI-Based Face Detection System

## 📌 Project Overview
The GenAI-Based Face Detection System is a computer vision application that uses AI technologies to detect human faces in images or real-time video. It aims to provide accurate face detection and can be extended with generative AI features for intelligent image analysis.

## 🎯 Objectives
- Detect human faces using AI and computer vision.
- Process images and webcam video in real time.
- Explore the integration of Generative AI with computer vision.
- Build a foundation for advanced AI-powered applications.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Computer Vision:** OpenCV
- **AI Models:** Pre-trained face detection models
- **GenAI Integration:** Hugging Face models (optional)
- **Environment:** VS Code / Jupyter Notebook

## ✨ Features
- Face detection from images.
- Real-time webcam face detection.
- Detection of multiple faces.
- AI-powered image analysis extensions.
- Modular design for future GenAI integration.

## ⚙️ Installation

Install the required Python library:

```bash
pip install opencv-python
```

For optional Hugging Face integration:

```bash
pip install transformers huggingface_hub
```

## ▶️ How to Run
1. Clone or download the project.
2. Install the required dependencies.
3. Configure the selected face detection model.
4. Run the main Python file:

```bash
python face_detection.py
```
